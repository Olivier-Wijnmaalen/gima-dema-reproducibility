# Publication review required

The files have been screened for common credential patterns, personal contact information, documentary source quotations and confidential Red Cross or Togo assessment content. None was identified in the selected publication package.

However, all four prompts embed DEMA framework definitions or maturity descriptions. The local research archive does not establish a licence allowing the author to grant public reuse rights over that framework wording.

Before publishing or adding an open-source licence:

1. confirm with the relevant DEMA/Red Cross rights holder that the framework wording may be redistributed publicly;
2. confirm the required attribution and citation;
3. select a licence only after confirming which material the author is entitled to license;
4. review the GitHub diff and run a final secret scan;
5. record the approval decision and date.

No `LICENSE` file is included intentionally. Adding a standard open-source licence without permission could grant rights the repository owner does not hold.
