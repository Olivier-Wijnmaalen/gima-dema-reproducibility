# Togo DEMA workshop report

[`Togo_DRR_EWS_Data_Workshop_Report_English_Translation.pdf`](Togo_DRR_EWS_Data_Workshop_Report_English_Translation.pdf) is an unofficial English translation of *Rapport – Atelier sur les données RRC et SAP au Togo: Ateliers nationaux sur la sélection des indicateurs et la maturité de l’écosystème des données au Togo (27–29 janvier 2026)*, authored by Mélanie Droogleever Fortuyn.

The translation is provided to make the workshop findings, DEMA diagnosis and action plan accessible to English-language reviewers. It preserves the report's substantive structure and presents the action-plan material in an accessible reformatted table. It is not a certified translation. If its wording differs from the French report, the French original is authoritative.

Permission to publish the report as an English derivative translation in this repository was confirmed by the repository owner on 22 November 2026.
